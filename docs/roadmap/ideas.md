| d8k9 | <a id="d8k9"></a>QMX: place the LO per band for the channels in use, not at FT8's dial | Operator intake 2026-11-07. In I/Q mode the LO sits 12 kHz below the dial and decode hears about 21 kHz either side of it; now that a QMX transmits a `TA` tone at least 7.5 kHz from its dial (radio.md, **TX timing on a QMX**), the dial need not be any channel's. On 20 m a dial near 14.080 to 14.082 would move FT4 off the window's top (19.5 kHz above the LO today, near the ADC filter's 21.8 kHz) and reach 14.090, where DXpeditions often run FT8 Fox and Hound, for a third channel; it also changes which signals the 32 dB image puts on ours. Wants evidence first: the edge cost FT4 nothing on the 2026-11-02 corpus, and hearing more needs a channel to decode it. Costs: the radio's tuning stops being a channel's dial, which reaches the pre-key frequency check, the app's frequency, the logged frequency and CAT band changes. Touches the same ground as epic [u8mc](several-channels.md)'s FT4 replies (shipped 2026-11-08). |

| I32 | <a id="I32"></a>P4: keep the QSO log in a database, not daily `.adi` files | Each QSO is one ADIF line in a day file on the P4's LittleFS. | syb2 | <a id="syb2"></a>Port A: a data channel past 255 bytes, streamed to the web app | Each message is one frame of positional binary, 255 bytes at most, so a log field means five edits and a flash of both boards, and the QSO row (221 bytes) has no room for A5's partner reference ([logging.md](../architecture/logging.md), **The four-place field chain**). **Direction (operator, 2026-10-24):** control, config and events stay typed binary; a data channel carries JSON and bulk text such as ADIF, which the sidekick streams to the web app unparsed; a fragmentation layer above the unchanged 255-byte, I2C-mappable frame lifts the cap; the protocol revs freely while pre-stable. First use: the log. **For the design:** the fragment header (routing without parsing); what the sidekick buffers versus streams; JSON per record or the stored ADIF; the browser-to-P4 direction (import, edits); what holds the web app to the P4's names. **Done-when:** the design settled in an issue: an epic proposed, or the idea declined. |
