# 0.2.0

## New
- Settings › Radio & bands › In the radio shows and sets the QMX's Tune power and Max. PA voltage. Lower Max. PA voltage for less output power.
- The SWR sweep sets Tune power beside Run, offers Set it to 25%, and labels each run with it.
- A running SWR sweep shows on every tab with Stop sweep, and the sweep page rejoins it.
- Settings › Software update shows what each release changes before you update.

## Changed
- Radio & bands offers only the bands your QMX has.
- Tapping a number, call or grid field selects it, so typing replaces it.
- The sidekick's web app comes with its firmware: one Update brings both.
- The app no longer stalls while a band change or a settings read waits on the main board.
- FT8 decodes no longer split into two batches when FT4 decodes arrive in the same slot.
- Flashing the sidekick over USB from the downloads page erases it, and it starts again as a new unit.

## Removed
- Settings › Radio & bands no longer has Protocol. FT4 is decoded beside FT8 with Also decode FT4.
