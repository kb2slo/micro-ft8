How to set up

  1. Flash the radio host — the PoE-P4, on its USB-C port next to the RJ45 (Ethernet) jack, the same port that powers it. Use Flash in browser below (Chrome/Edge) or the CLI commands.
  2. Flash the Atom separately — the AtomS3 Lite is its own USB-C flash. Do this before you hang it off Grove; the host does not program it over the cable for first install.
  3. Then follow Getting started: connecting the radio, joining the Atom’s own network, pairing, and your first QSO. A newly flashed Atom serves the app at once; one flashed with the 0.1.0 release has only its setup pages at first, and they say how to install it.

Assets

Flashing over USB erases the board. Flashed this way, the sidekick forgets its WiFi and pairing and starts as a new unit, and the main board can lose the station’s settings and QSO logs. It is for a new setup or a full recovery; updates are over the air, from the app. Save your log first: in the app, on QSOs, tap Download full ADI.

Flash in browser uses the Web Serial API (Chrome or Edge on desktop). Safari and Firefox: use the esptool.py commands below. Hold the device’s reset/boot as needed if the port does not appear.

    Flash (CLI)

    Merged images at 0x0. Use a data-capable USB-C cable.

    PoE-P4 (U213) — flash/power on the USB-C next to RJ45

    esptool.py --chip esp32p4 write_flash 0x0 microft8-poe-p4-dev.bin

    AtomS3 Lite

    esptool.py --chip esp32s3 write_flash 0x0 microft8-sidekick-dev.bin
