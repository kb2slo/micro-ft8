How to set up

  1. Flash one radio host — either the Cardputer ADV or the PoE-P4 (not both for one station). Use Flash in browser below (Chrome/Edge) or the CLI commands.
  2. Flash the Atom separately — the AtomS3 Lite is its own USB-C flash. Do this before you hang it off Grove; the host does not program it over the cable for first install.
  3. Connect with a Grove cable — Port A on the ADV, or the Grove port on the PoE-P4 (a cable ships with the P4). The Atom takes 5 V from Grove once the host is powered.
  4. PoE-P4 USB-C ports — the board has two, and they are not interchangeable:
    • Next to the RJ45 / Ethernet — power in (5 V USB-C supply) and flashing / serial. Labelled something like USB-C PROG & OTG.
    • On the side of the unit — the radio only. Plug the QMX/QDX here (USB host).
    Do not put the radio on the Ethernet-side port, and do not expect that side port to power the board.
  5. Cardputer ADV USB-C — one port does flash and radio hosting: flash first, then plug the QMX/QDX into the same USB-C when you operate (or use a powered hub if you need both at once on the desk).
  6. Set up Wi‑Fi on the Atom — on first boot (or after “forget network”), the Atom opens its own access point named MicroFT8-SK-… (open, no password). From your phone or computer:
    • Join that Wi‑Fi network.
    • Open a browser to http://192.168.4.1/ (many phones also pop a sign-in / captive-portal sheet that lands on the same page).
    • Pick your home/camp network, enter the password, and submit. The Atom restarts and joins that network.
  7. Open the UI — on the same Wi‑Fi as the Atom, browse http://micro-ft8.local/. Pair with the Atom’s user button when asked (needed for clock sync and other writes).

Assets

Flash in browser uses the Web Serial API (Chrome or Edge on desktop). Safari and Firefox: use the esptool.py commands below. Hold the device’s reset/boot as needed if the port does not appear. 

    
  
    

  
    
    
    Flash (CLI)
    
    
    Merged images at 0x0. Use a data-capable USB-C cable.
    
    
    Cardputer ADV
    
    
    esptool.py --chip esp32s3 write_flash 0x0 microft8-adv-continuous.bin
    
    
    PoE-P4 (U213) — flash/power on the USB-C next to RJ45
    
    
    esptool.py --chip esp32p4 write_flash 0x0 microft8-poe-p4-continuous.bin
    
    
    AtomS3 Lite
    
    
    esptool.py --chip esp32s3 write_flash 0x0 microft8-sidekick-continuous.bin
